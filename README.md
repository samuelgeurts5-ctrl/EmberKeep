# EmberKeep

**A fantasy virtual tabletop for your next adventure.**

EmberKeep is an early-stage 2D virtual tabletop prototype built with React, TypeScript, and Vite. The visual direction uses dark mahogany, burgundy, parchment, and aged-bronze tones.

## Prototype features

- Interactive 18 × 12 tabletop grid
- Select party tokens and move heroes to nearby empty tiles
- Party panel with character health
- d20, d6, and initiative dice actions
- Encounter round counter and scene event log
- Journal view
- Grid and fog preview toggles

## Run in GitHub Codespaces

1. Open the repository in GitHub.
2. Choose **Code → Codespaces → Create codespace on main**.
3. In the terminal, run `npm install`.
4. Then run `npm run dev -- --host 0.0.0.0`.
5. Open the forwarded port when Codespaces offers it.

## Current scope

This is a frontend prototype. Online multiplayer, accounts, cloud-saved campaigns, real fog-of-war permissions, map editing, and a production rules engine are not implemented yet.
